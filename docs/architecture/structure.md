# Структура папок и декомпозиция

## Компонент — это папка

```
ShowCard/
  ShowCard.tsx              # View: всегда есть
  index.ts                  # barrel: всегда есть
  ShowCard.types.ts         # пропсы: если компонент их принимает
  useShowCardPresenter.ts   # Presenter: если компоненту нужно что-то готовить
  ShowCard.module.css       # стили: только если не хватает Tailwind
  ShowCard.test.tsx         # тесты: только если пишем тесты
  formatRuntime.ts          # утилиты и вспомогательные хуки этого компонента
```

**Создаём только то, что нужно.** Нет стилей — нет файла стилей. Не пишем тесты — нет тест-файла. Нечего готовить — нет презентера.

Имена файлов повторяют имя компонента: `ShowCard.tsx`, `ShowCard.types.ts`, `useShowCardPresenter.ts`. Папка компонента называется в PascalCase.

## Barrel

В каждой папке компонента лежит `index.ts`, который экспортирует компонент и его типы. Снаружи папки компонент импортируется только через barrel:

```ts
import { ShowCard } from '@/app/ShowList/ShowCard'; // ✅
import { ShowCard } from '@/app/ShowList/ShowCard/ShowCard'; // ❌ импорт мимо barrel
```

## Декомпозиция

Если компонент состоит из других компонентов, дочерние компоненты лежат папками **внутри папки родителя** и устроены по тем же правилам:

```
ShowList/
  ShowList.tsx
  useShowListPresenter.ts
  index.ts
  ShowCard/
    ShowCard.tsx
    index.ts
```

## Переиспользуемые компоненты

- `src/components/` — компоненты, которые **уже** переиспользуются в разных частях приложения.
  - Исключение — базовые элементы UI kit (кнопка, поле ввода, бейдж, скелетон, чипс): они почти наверняка будут переиспользоваться, поэтому кладутся сюда сразу.
  - Всё остальное (пагинация, поле поиска, карточка) сначала живёт в папке фичи или экрана, где используется. В `src/components/` компонент переезжает, когда появляется второе место использования.
- Если компонент переиспользуется только внутри одного крупного компонента (виджета) в разных его частях, на уровне этого виджета создаётся своя папка `components/`:

```
ShowSearch/
  ShowSearch.tsx
  components/
    GenreChip/          # используется и в Filters, и в ShowList
  Filters/
  ShowList/
```

## Верхний уровень `src/`

```
src/
  main.tsx        # точка входа: монтирует App
  index.css       # токены дизайн-системы и Tailwind
  app/            # компонент App; дальше вся иерархия приложения
  components/     # UI kit и компоненты, которые уже переиспользуются
    ui/           # shadcn-примитивы — вендорный код
  api/            # временно: работа с сетью (см. temporary.md)
  lib/            # общие утилиты (cn и т. п.)
```

Папка `app/` — это папка компонента `App` (`app/App.tsx`, `app/useAppPresenter.ts`). Это единственное исключение из правила «папка называется как компонент», потому что `app` одновременно является корнем иерархии приложения.

## shadcn/ui

`src/components/ui/` — вендорный код: его генерирует CLI shadcn, и мы правим его только для подгонки под дизайн-систему. Архитектурные правила и лимит строк на эту папку не распространяются.

Импортировать `@/components/ui/*` можно **только из обёрток** в `src/components/<Name>/`. Остальное приложение работает только с нашими компонентами (`@/components/Button`), а вендор изолирован за обёрткой, как внешний сервис за адаптером.
