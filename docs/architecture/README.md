# Simple Architecture — конспект

Simple Architecture — это переосмысление «Чистой архитектуры» (Clean Architecture, Роберт Мартин), объединённое с VIPER из iOS-разработки и перенесённое на React.

VIPER: **V**iew, **I**nteractor, **P**resenter, **E**ntity, **R**outer.

Конспект пополняется по мере прохождения курса.
