# Поиск сериалов

Макеты: канвас Claude Design «TV Shows Explorer», ряд «Экраны · поиск сериалов» (артборды 1–6).
Данные: `tvmazeApi.searchShows` (не больше 10 результатов). Одна страница, без роутинга.

## Состояния экрана

| #   | Состояние         | Когда                                        | Что видно                                                                                  |
| --- | ----------------- | -------------------------------------------- | ------------------------------------------------------------------------------------------ |
| 1   | Старт             | строка поиска пустая                         | поле поиска в фокусе, иллюстрация «пустой кинозал с проектором»                            |
| 2   | Загрузка          | запрос в полёте и нет результатов для показа | спиннер в поле, overline «Ищем «{запрос}»…», скелетоны 5 чипсов и 3 карточек               |
| 3   | Результаты        | есть результаты                              | overline «Результатов по «{запрос}»: N», чипсы жанров, сетка карточек, пагинация           |
| 4   | Фильтр по жанру   | выбран жанр                                  | overline «{жанр} · M из N», кнопка «Сбросить фильтр», выбранный жанр подсвечен в карточках |
| 5   | Ничего не найдено | запрос выполнен, результатов 0               | панель «телевизор с помехами»: «По «{запрос}» — только помехи», кнопка «Очистить поиск»    |
| 6   | Ошибка сети       | запрос завершился ошибкой                    | панель «потерян сигнал»: «Сигнал потерян», текст об ошибке, кнопка «Повторить»             |

## Поведение

- Поиск запускается при вводе, с debounce 400 мс. Очистка поля возвращает на старт.
- Пока грузится новый запрос, предыдущие результаты остаются на экране, в поле крутится спиннер.
- Состояние (запрос, жанр, страница) хранится в состоянии компонента, не в URL.

### Жанры

- Чипсы: «Все · N» и по одному на каждый жанр из результатов со счётчиком, по убыванию счётчика.
- Выбирается один жанр. Повторный клик по выбранному или «Сбросить фильтр» возвращают «Все».
- Смена жанра или запроса возвращает на страницу 1.

### Пагинация

- Клиентская, 3 карточки на странице.
- Если страница одна, пагинация скрыта.

### Карточка

- Постер `image.medium`, пропорции 2:3. При `image === null` — заглушка «кадр плёнки»: название и год.
- Рейтинг всегда виден: `★ {rating.average}` янтарным, при `null` — серый `★ —`.
- Бейдж «В эфире» — только при `status === 'Running'`.
- Overline: тип по-русски и годы. `Scripted` → Сериал, `Reality` → Реалити, `Animation` → Анимация, `Documentary` → Документальный, остальные — как есть. Годы: `premiered–ended`, для идущих — только год начала.
- Название — заголовок, не ссылка.
- Мета: канал (`network.name`, иначе `webChannel.name`) · длительность в минутах · жанры. В режиме фильтра выбранный жанр подсвечен.
- Описание: `summary` без HTML, не больше 3 строк.

### Сетка

- 3 колонки на десктопе, 2 на планшете, 1 на телефоне.

## Оформление

- Фон страницы: плёночное зерно с виньеткой (вариант 1 с артборда «Фоны»).
- Шапка: логотип «TV·Explorer» без навигации.
