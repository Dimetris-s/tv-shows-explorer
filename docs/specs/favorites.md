# Избранное

Макеты: канвас Claude Design «TV Shows Explorer», ряд «Избранное» (артборды F1–F6). Мобильных макетов нет: грид и оверлей адаптируются так же, как поиск.

## Где хранится

- Вся логика на сервере, в памяти процесса: `favorite[clientId][showId] = { show, addedAt }`. Без базы данных, данные пропадают при рестарте сервера.
- Избранное своё у каждого браузера: сервер выдаёт анонимный `clientId` в httpOnly cookie (SameSite=Lax), если её нет. Логинов нет.
- При добавлении сервер сам получает шоу из TVmaze `/shows/:id` (через кеш на 5 минут) и сохраняет снимок `Show`. Клиент передаёт только id.

## API

| Запрос                        | Ответ                                                                 |
| ----------------------------- | --------------------------------------------------------------------- |
| `GET /api/shows?q&genre&page` | `items: ShowListItem[]` с флагом `isFavorite` для этого клиента       |
| `GET /api/favorites`          | `ShowListItem[]` (все `isFavorite: true`), недавно добавленные сверху |
| `GET /api/favorites/count`    | `{ count }`                                                           |
| `PUT /api/favorites/:id`      | `{ isFavorite: true, count }`; повторное добавление — тоже `200`      |
| `DELETE /api/favorites/:id`   | `{ isFavorite: false, count }`; удаление отсутствующего — тоже `200`  |

Ошибки: `400` — `id` не целое положительное число, `404` — шоу нет в TVmaze, `502` — TVmaze недоступен. Тело ошибки — `{ error }`.

## Звёздочка на карточке

- Круглая кнопка 44 px в правом верхнем углу постера. Выключена — контур, включена — янтарная заливка, hover — янтарная обводка.
- `aria-pressed`, `aria-label`: «Добавить в избранное» / «Убрать из избранного».
- Состояние: флаг `isFavorite` из ответа сервера, поверх него — локальные переключения этой сессии. Переключение в оверлее сразу видно в поиске и наоборот.
- Клик переключает звезду сразу (оптимистично) и отправляет `PUT` или `DELETE`. Счётчик берётся из ответа сервера.
- Успех — тост «Добавлено в избранное» / «Убрано из избранного» с названием шоу.
- Ошибка — звезда возвращается в прежнее состояние, тост «Не удалось обновить избранное» с текстом «Звёздочка вернулась как было. Попробуйте ещё раз.».

## Кнопка в шапке

- «★ Избранное» справа в шапке, с бейджем-счётчиком.
- Счётчик загружается при старте приложения (`GET /api/favorites/count`). Пока не загружен или загрузка упала — без бейджа.
- 0 — серый бейдж и контурная звезда, N > 0 — янтарный бейдж и закрашенная звезда.
- Клик открывает оверлей «Избранное».

## Оверлей «Избранное»

- Полноэкранный диалог поверх поиска. Поиск под ним не размонтируется: запрос, жанр и страница сохраняются.
- Закрывается кнопкой ✕ и Esc.
- Шапка: подпись «Недавно добавленные сверху», заголовок «Избранное · N».
- Список: тот же грид карточек, что в поиске, без пагинации и фильтра по жанрам, недавно добавленные сверху.
- Снятая звезда сразу убирает карточку из списка.
- Данные грузятся при каждом открытии.

### Состояния

| Состояние | Когда                     | Что видно                                                                                                 |
| --------- | ------------------------- | --------------------------------------------------------------------------------------------------------- |
| Загрузка  | первый запрос в полёте    | скелетоны 3 карточек                                                                                      |
| Список    | есть избранное            | грид карточек                                                                                             |
| Пусто     | избранного нет            | панель «Пустой зал»: «Пока пусто», «Отмечайте сериалы звёздочкой…», кнопка «К поиску» (закрывает оверлей) |
| Ошибка    | запрос завершился ошибкой | панель «Сигнал потерян»: «Не удалось загрузить избранное…», кнопка «Повторить»                            |

## Тосты

- Внизу справа, тёмная карточка дизайн-системы. Иконка: янтарная звезда (добавлено), контурная серая (убрано), красный круг (ошибка).
- Показывает презентер звёздочки по результату таски. Таска тостов не знает.
