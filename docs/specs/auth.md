# Авторизация

Вход только по email: без пароля, регистрации и восстановления доступа. Первый вход с новым email создаёт пользователя.

## Пользователь

- Пользователь — это email. Email нормализуется на сервере: пробелы по краям убираются, регистр приводится к нижнему. `Foo@Mail.com ` и `foo@mail.com` — один пользователь.
- Избранное принадлежит пользователю (`docs/specs/favorites.md`). Вышел и зашёл под тем же email — видит прежний список.
- Данные живут в памяти процесса сервера: рестарт стирает и сессии, и избранное.

## Сессия

- Вход создаёт сессию: случайный `sessionId` в httpOnly cookie `session` (Secure, SameSite=Lax, 30 дней). Из-за Secure браузер принимает cookie только по HTTPS или на `localhost`, на сервере `session[sessionId] = email`.
- Выход удаляет сессию на сервере и стирает cookie.
- Cookie недоступна JS, поэтому при старте фронт спрашивает сервер, кто он (`GET /api/auth/me`). Пока ответа нет, шапка не показывает ни «Войти», ни меню пользователя.
- Если запрос избранного вернул `401` (сессия пропала после рестарта сервера), фронт считает пользователя вышедшим.

## API

| Запрос                  | Тело        | Ответ                                                      |
| ----------------------- | ----------- | ---------------------------------------------------------- |
| `GET /api/auth/me`      | —           | `{ user: { email } \| null }`                              |
| `POST /api/auth/login`  | `{ email }` | `{ user: { email } }` и cookie `session`; `400` — не email |
| `POST /api/auth/logout` | —           | `204`, cookie стёрта; без сессии — тоже `204`              |

## Аноним

- Ищет и смотрит сериалы как раньше. В ответе поиска все `isFavorite: false`.
- Звёздочек на карточках нет.
- В шапке вместо «Избранное» кнопка «Войти», ведёт на `/login`.
- Запросы `/api/favorites*` без сессии — `401 { error }`.

## Страница входа `/login`

- Заголовок «Вход», подпись «Только email: без пароля и регистрации. Избранное привязано к адресу».
- Поле email (`type="email"`, автозаполнение `email`) и кнопка «Войти». Пока запрос в полёте, кнопка неактивна и подписана «Входим…».
- Ошибки под полем: `400` — «Похоже, это не email», остальное — текст ошибки сети.
- Успех — переход на главную и тост «Вы вошли» с email в описании.
- Залогиненный пользователь, открывший `/login`, сразу попадает на главную.
- Ссылка «К поиску» ведёт на главную. Состояние поиска при переходе на `/login` и обратно не сохраняется.

## Шапка пользователя

- Слева от «Избранного»: email (обрезается многоточием) и кнопка «Выйти».
- Выход: запрос, затем аноним на текущей странице. Ошибка — тост «Не удалось выйти», пользователь остаётся.
- Вход и выход сбрасывают локальные переключения звёздочек и перезагружают счётчик избранного. Результаты поиска кэшируются отдельно для каждого пользователя, поэтому флаги звёздочек не переходят от одного пользователя к другому.
