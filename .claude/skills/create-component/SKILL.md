# Создание компонента

Структуру компонента создаёт генератор, детерминированно. Твоя задача — выбрать путь и флаги, а затем наполнить файлы.

## 1. Выбери место

| Компонент                                            | Путь                                |
| ---------------------------------------------------- | ----------------------------------- |
| Часть конкретного родителя                           | `<папка родителя>/<Name>`           |
| Переиспользуется в нескольких частях одного виджета  | `<папка виджета>/components/<Name>` |
| Переиспользуется во всём приложении (дизайн-система) | `src/components/<Name>`             |
| Обёртка над shadcn-примитивом                        | `src/components/<Name>` + `--wrap`  |

Имя — PascalCase. Если не очевидно, куда положить компонент, спроси пользователя.

## 2. Выбери флаги: только то, что нужно

| Флаг               | Когда                                                                       |
| ------------------ | --------------------------------------------------------------------------- |
| `--presenter`      | компоненту нужно готовить данные, флаги, обработчики, вызывать хуки         |
| `--props`          | компонент принимает пропсы (создаётся `<Name>.types.ts` с `<Name>Props`)    |
| `--styles`         | Tailwind не хватает (создаётся `<Name>.module.css`)                         |
| `--test`           | пользователь просит тесты                                                   |
| `--wrap <ui-file>` | обёртка над `src/components/ui/<ui-file>.tsx`; имя = имя экспорта примитива |

`<Name>.tsx` и `index.ts` создаются всегда.

## 3. Запусти

```sh
pnpm gen:component src/app/ShowSearch/ShowList --presenter --props
pnpm gen:component src/components/Button --wrap button
```

Генератор откажет, если компонент уже есть, имя не в PascalCase или путь вне `src/`.

## 4. Наполни

- Сгенерированный код — заготовка с плейсхолдером `title`. Замени его реальными пропсами и данными.
- Пропсы опиши в `<Name>.types.ts`. Компонент и презентер используют один и тот же тип.
- Логику, хуки и обработчики пиши в презентере, в компоненте только JSX (правила: `.claude/rules/view-presenter.md`).
- Подключи компонент у потребителя через barrel: `import { Name } from './Name'` или `@/components/Name`.
- Если позже понадобится файл, которого не было (презентер, стили), создай его руками по тем же именам: `use<Name>Presenter.ts`, `<Name>.module.css`, `<Name>.types.ts`. Генератор работает только для новых компонентов. Тип пропсов экспортируй из `index.ts`.
- В конце запусти `pnpm check`.

## Новый shadcn-примитив

```sh
pnpm dlx shadcn@latest add <name>                          # в src/components/ui/<name>.tsx
pnpm gen:component src/components/<Name> --wrap <name>      # обёртка
```

Если примитив экспортирует несколько частей (`Card`, `CardHeader`, …), сгенерируй обёртку для главного экспорта, а остальные части добавь в обёртку вручную, по тому же образцу.
