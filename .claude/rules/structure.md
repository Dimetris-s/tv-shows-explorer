# Структура `src/`

Подробности: `docs/architecture/structure.md`.

```
src/
  main.tsx        # точка входа
  index.css       # токены дизайн-системы и Tailwind
  app/            # папка компонента App (единственное исключение из правила именования)
  components/     # UI kit и компоненты, которые уже переиспользуются
    ui/           # shadcn: вендорный код, правила не действуют
  tasks/          # переиспользуемые таски
  hooks/          # переиспользуемые хуки
  types/          # переиспользуемые типы
  services/       # http-клиент; временно useQuery и конфиг TVmaze (docs/architecture/temporary.md)
  lib/            # общие утилиты
```

## Папка компонента

| Файл                        | Когда                                     |
| --------------------------- | ----------------------------------------- |
| `Name.tsx`                  | всегда                                    |
| `index.ts`                  | всегда (barrel)                           |
| `Name.types.ts`             | компонент принимает пропсы                |
| `Name.module.css`           | Tailwind не хватает                       |
| `Name.test.tsx`             | пишем тесты                               |
| `data.ts`                   | статические данные для JSX                |
| `logic/useNamePresenter.ts` | компоненту нужно что-то готовить          |
| `logic/helperName.ts`       | хелперы и вспомогательные хуки презентера |
| `logic/tasks/verbName.ts`   | таски компонента (правила: `tasks.md`)    |

- Создавай только то, что нужно. Структуру создаёт `pnpm gen:component` (скилл `create-component`).
- Дочерний компонент — папка внутри родителя.
- `logic/` (строчными) — всё без отображения. Её файлы импортирует только сам компонент: ни дети, ни соседи.
- Переиспользование, только при втором месте использования:
  - таски: `<Widget>/tasks/` (части одного виджета) → `src/tasks/` (разные части приложения);
  - хуки: сразу `src/hooks/`, уровня виджета нет;
  - типы: `<Widget>/types/` → `src/types/`.
- `X/tasks/` и `X/types/` видны всему поддереву `X/`. Barrel у `tasks/` нет: `@/tasks/searchShows`.
- Компонент, переиспользуемый в нескольких частях одного виджета, кладётся в `components/` этого виджета.
- В `src/components/` — только базовые элементы UI kit (кнопка, поле ввода, бейдж, скелетон, чипс) и компоненты, которые уже используются в нескольких местах приложения.
- Компонент фичи или экрана (пагинация, поле поиска, карточка) живёт в папке этой фичи, даже если «наверное, пригодится где-то ещё». Переезжает в `src/components/` при втором месте использования.
- Снаружи папки компонента импортируй только саму папку: `@/app/ShowList/ShowCard`, а не `…/ShowCard/ShowCard`.
- `@/components/ui/*` импортируют только обёртки в `src/components/<Name>/`.
- Не больше 120 строк на `.ts`/`.tsx` (без пустых строк и комментариев). Упёрся в лимит — скилл `decompose-component`.
