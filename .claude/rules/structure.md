# Структура `src/`

Подробности: `docs/architecture/structure.md`.

```
src/
  main.tsx        # точка входа
  index.css       # токены дизайн-системы и Tailwind
  app/            # папка компонента App (единственное исключение из правила именования)
  components/     # переиспользуемые компоненты (дизайн-система)
    ui/           # shadcn: вендорный код, правила не действуют
  api/            # временно: http, tvmaze, useQuery (docs/architecture/temporary.md)
  lib/            # общие утилиты
```

## Папка компонента

| Файл                  | Когда                            |
| --------------------- | -------------------------------- |
| `Name.tsx`            | всегда                           |
| `index.ts`            | всегда (barrel)                  |
| `Name.types.ts`       | компонент принимает пропсы       |
| `useNamePresenter.ts` | компоненту нужно что-то готовить |
| `Name.module.css`     | Tailwind не хватает              |
| `Name.test.tsx`       | пишем тесты                      |
| `utilName.ts`         | утилиты и вспомогательные хуки   |

- Создавай только то, что нужно. Структуру создаёт `pnpm gen:component` (скилл `create-component`).
- Дочерний компонент — папка внутри родителя.
- Компонент, переиспользуемый в нескольких частях одного виджета, кладётся в `components/` этого виджета.
- Компонент, переиспользуемый во всём приложении, кладётся в `src/components/`.
- Снаружи папки компонента импортируй только саму папку: `@/app/ShowList/ShowCard`, а не `…/ShowCard/ShowCard`.
- `@/components/ui/*` импортируют только обёртки в `src/components/<Name>/`.
- Не больше 120 строк на `.ts`/`.tsx` (без пустых строк и комментариев). Упёрся в лимит — скилл `decompose-component`.
