# Tasks

Мотивация и примеры: `docs/architecture/tasks.md`.

- Таска — обычная (можно `async`) функция, реализующая бизнес-логику: шаг, который описывается в спеке без слов «экран», «кнопка», «страница».
- Имя — глагол в camelCase: `searchShows`, `filterShowsByGenre`. Файл называется как функция.
- Один файл — один именованный экспорт таски. Большая таска — папка `verbName/` с `verbName.ts` и частями; её `index.ts` содержит только `export { verbName } from './verbName';`.
- Без React: не импортируй `react*`, хуки, компоненты, `.tsx`, презентеры. Побочные эффекты разрешены: `httpGet`, сторы напрямую (без thunk/saga), `AbortSignal`.
- Сеть — только через `httpGet` из `@/services/http`. Отдельного API-слоя нет. DTO переводи в свой тип на границе таски.
- Вызывают таску презентер, его хуки или другие таски. Не View.
- Навигацию в таске не делай: это работа презентера.
- Место: `Name/logic/tasks/` (один компонент) → `<Widget>/tasks/` (несколько частей виджета) → `src/tasks/` (всё приложение). Переезд — при втором месте использования.
- Новая таска создаётся генератором (скилл `create-task`).
